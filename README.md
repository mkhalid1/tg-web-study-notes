# TG-WEB 対策ノート

ヒューマネージの適性検査TG-WEBのための、無料の学習ガイドです。従来型と新型の見分け方、従来型で出る暗号・推論・数列・展開図・言語の解き方、性格・適性検査への向き合い方、結果の扱われ方、7日間と2日間の学習プランまでをまとめました。オリジナルの練習問題21問（各ページの17問と5分診断の4問）には、すべて解説がついています。TG-WEBについての事実はヒューマネージの公式ページだけを根拠にし、就活サイトの数字は「非公式の目安」と明記して[出典](docs/sources.md)を示しています。

まず力試しをしたい人は、TG-WEB従来型と同じ形式の[PrepClubsの無料TG-WEB形式模擬テスト](https://prepclubs.com/ja/tg-web-taisaku?utm_source=github&utm_medium=referral&utm_campaign=7n35ny&utm_content=tg-web)（21問・30分）か、このリポジトリの短い[5分診断](docs/diagnostic.md)から始めてください。

## まずはここから

1. **従来型か新型かの見当をつける。** [従来型と新型の見分け方](docs/how-to-tell-types.md)を読みます。分からなければ従来型から準備します。
2. **苦手なタイプを見つける。** [5分診断](docs/diagnostic.md)の4問を解きます。どのページから始めるかが分かります。
3. **苦手なタイプから練習する。** そのページの手順を読み、練習問題（3〜5問）を解きます。
4. **計画に沿って仕上げる。** [7日間プラン](docs/study-plans.md#7日間プラン)、時間がなければ[2日間プラン](docs/study-plans.md#2日間プラン)に進みます。

## 基本情報

| 項目 | 内容 |
|---|---|
| 提供元 | 株式会社ヒューマネージ |
| 導入実績 | 導入3,200社以上、年間60万人以上が利用（公式） |
| 能力検査の例 | 判断推理力検査 i9（30分）、基礎能力検査 i9neo（15分）、英語能力検査 i9e（15分）（公式） |
| 出題 | i9とi9neoはIRT（項目反応理論）に基づきランダムに出題（公式） |
| 受検方式 | WEB、AI監視型WEB（TG-WEB eye）、テストセンター、オンライン監視型WEB会場、マークシート（公式） |
| 性格・適性の検査 | B5、A8、G9、E9、W8、Q1、U1、P8 など（公式） |
| 合格ライン | 公表されていない。企業ごとに判断 |
| 従来型・新型 | 就活サイトでの呼び名。問題数と時間の目安は非公式 |

出典：[ヒューマネージ公式（TG-WEB）](https://tg-web.humanage.co.jp/)、[知的能力検査の公式ページ](https://tg-web.humanage.co.jp/lineup/i9.html)、[TG-WEB eyeの公式ページ](https://www.humanage.co.jp/service/assessment/tg-web/eye/index.html)（2026年11月25日確認）

## 問題タイプの一覧

| タイプ | 型 | 何をするか | 練習問題 | ページ |
|---|---|---|---|---|
| 暗号 | 従来型 計数 | 置き換えの規則を見抜く | 3問 | [暗号](docs/sections/code-puzzles.md) |
| 推論 | 従来型 計数 | 条件から順位・配置・うそつきを決める | 3問 | [推論](docs/sections/logic-puzzles.md) |
| 数列 | 従来型 計数 | 並んだ数の規則を見つける | 3問 | [数列](docs/sections/number-series.md) |
| 展開図・図形 | 従来型 計数 | 展開図、一筆書き、図形の個数 | 3問（図つき） | [展開図・図形](docs/sections/figures.md) |
| 長文読解・空欄補充・並べ替え | 従来型 言語 | 本文を根拠に選ぶ、文のつながりを読む | 5問 | [言語（従来型）](docs/sections/verbal.md) |
| 計算・表の読み取り・語彙 | 新型 | 短時間で大量に処理する | 概要と練習法 | [新型の概要](docs/sections/new-type.md) |
| 性格・適性 | 共通 | 普段の自分をぶれずに答える | なし（正解がない） | [性格・適性検査](docs/personality.md) |

能力検査の各ページは、何を測る問題か、問題の形、解き方の手順、よくある落とし穴、時間配分、オリジナルの練習問題と解説、自己採点の順に並んでいます。

## このリポジトリの使い方

- **GitHub上でそのまま読めます。** どのページにも「前へ」「次へ」「目次に戻る」のリンクがあるので、本のように順番に読み進められます。
- **答えを見る前に、自分の答えを決める。** 解答は「解答と解説」を開くと表示されます。先に答えを決めてから開いてください。
- **正解した問題の解説も読む。** 解説の多くは、近い選択肢がなぜ違うかを説明しています。そこが本番で迷うところです。
- **ミスノートをつける。** 間違えた問題ごとに、原因と次からの一手を書きます。書き方は[学習プラン](docs/study-plans.md#ミスノートのつけ方)にあります。
- **時間を計って解く。** このガイドは解き方を教えます。ペースは、[PrepClubsの無料TG-WEB形式模擬テスト](https://prepclubs.com/ja/tg-web-taisaku?utm_source=github&utm_medium=referral&utm_campaign=7n35ny&utm_content=tg-web)のような時間を計った練習で身につけます。
- **クローンもフォークも自由にどうぞ。** 自分用にメモを書き込んでも構いません。GitBookでも読める構成です（[SUMMARY.md](SUMMARY.md)）。

## 練習問題について

練習問題21問（各ページの17問と5分診断の4問）は、すべてこのガイドのために作ったオリジナル問題です。TG-WEBの実際の問題、ヒューマネージの資料、ほかの対策サイトや問題集から取ったものはありません。図もこのガイドのために描いたものです。問題の形は、公式ページの説明と、就活サイトで一般に紹介されている出題タイプに合わせています。

## 誤りを見つけたら

事実の誤り、公式ページの変更、答えが違うと思う問題に気づいたら、[Issue](https://github.com/mkhalid1/tg-web-study-notes/issues)かプルリクエストで知らせてください。事実の訂正には、ヒューマネージの公式ページか企業自身のページへのリンクを添えてください。
