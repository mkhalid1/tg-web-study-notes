# 新型（計数・言語）の概要

**ひとことで言うと：** 1問ごとは易しめで、短い時間に多くの問題を処理するスピード型です。従来型のように「解き方を知らないと手が止まる」問題は少なく、速さと正確さの勝負になります。

このページには練習問題を入れていません。新型は1問ごとの難しさより処理量が問われるので、問題数の少ない例題よりも、時間を計った計算や語彙の練習のほうが役に立つからです。ここでは、何が出るか、どう練習するかを整理します。

## 公式ページで確認できること

「新型」という言葉は公式ページでは確認できません。ただ、就活サイトが説明する新型の中身は、ヒューマネージの基礎能力検査 i9neo の公式説明とよく重なります。このガイドでは新型をi9neoに近いものとして扱いますが、これはこのガイドの解釈です。

| 項目 | i9neoの公式説明 |
|---|---|
| 検査時間 | 15分 |
| 言語 | 意味の近い単語や対立する単語、言葉の意味を問う問題 |
| 数理 | 表の読み取りや計算の穴埋め問題 |
| 特徴 | i9に比べて検査時間が短く、設問数が多い。正確さやスピードを重視した力の測定に向いている |
| 出題 | IRT（項目反応理論）に基づきランダムに出題 |
| 基準レベル | 4年制大学卒業レベル |
| 受検方式 | オンラインAI監視型WEB方式、WEB方式 |

就活サイトの目安（非公式）では、新型の言語は34問で7分、計数は36問で8分です。1問あたり十数秒しかない計算になります。この内訳はヒューマネージの公表ではありません。

## 計数：何が出て、どう解くか

公式に挙がっているのは「表の読み取り」と「計算の穴埋め」です。

- **計算の穴埋め：** 式の一部が空欄になっています。右辺から逆算すると速く解けます。「A÷（　）＋B＝C」の形なら、まず C から B を引き、A をその数で割れば空欄の数になります。
- **表の読み取り：** 表から必要な数字を拾い、割合や差を出します。表全体を読まずに、設問が聞いている行と列だけを見るのがコツです。

### 練習のしかた

1. **四則演算の逆算を、紙に書かずにできるようにする。** 九九の逆（56は7×8）、よく出る割合（1/8＝12.5%など）はすぐ出るようにしておきます。
2. **1分間に何問解けるかを計る。** 新型では、1問ごとの正解率より、時間内に解ける数が点を左右します。
3. **分からない問題は5秒で飛ばす。** 1問に30秒かけると、易しい問題を3つ落とすのと同じです。

## 言語：何が出て、どう解くか

公式に挙がっているのは「意味の近い単語」「対立する単語」「言葉の意味」です。就活サイトでは、同義語、対義語、ことわざ・慣用句などとして紹介されています。

- **同義語・対義語：** 「楽観」と「悲観」のように、一方の漢字を入れ替えると対義語になる語が多く使われます。片方の漢字が共通していれば、もう片方の漢字の意味で判断します。
- **言葉の意味：** 日常であまり使わない言葉が出ることがあります。知らない言葉に時間をかけず、知っている言葉で確実に点を取るのが基本です。

### 練習のしかた

1. **二字熟語の対義語を、組で覚える。** 「需要と供給」「具体と抽象」「保守と革新」のように、組で口に出して覚えます。
2. **読めるのに意味があいまいな言葉を拾い出す。** 新聞や本で見かけて意味があいまいな言葉を、その場で調べる習慣が一番の対策です。
3. **迷ったら最初の印象で選ぶ。** 語彙問題は考えても答えが出ないことが多いので、時間を計算問題に回します。

## 従来型との違いのまとめ

| | 従来型 | 新型 |
|---|---|---|
| 1問の難しさ | 高め。解き方を知らないと手が止まる | 低め。知っていればすぐ解ける |
| 時間との関係 | 1問に1〜2分かけられる（非公式の目安） | 1問十数秒（非公式の目安） |
| 主な対策 | 型と手順を覚える | 時間を計って処理速度を上げる |
| 近い公式検査（このガイドの解釈） | 判断推理力検査 i9 | 基礎能力検査 i9neo |

どちらが出るか分からないときの準備の順番は、[従来型と新型の見分け方](../how-to-tell-types.md#どちらか分からないときの準備)にまとめています。

## 次のステップ

PrepClubsの無料TG-WEB形式模擬テスト（21問・30分）は従来型と同じ形式なので、新型の練習にはなりません。新型が出そうな場合も、従来型の型を先に押さえておくと安心です。従来型の練習には[TG-WEB形式の無料模擬テスト（PrepClubs）](https://prepclubs.com/ja/tg-web-taisaku?utm_source=github&utm_medium=referral&utm_campaign=7n35ny&utm_content=tg-web)を使い、新型は上の練習のしかたで計算と語彙の速さを鍛えてください。
