# 数列

**ひとことで言うと：** 並んだ数の規則を見つけ、空欄に入る数を答える問題です。

数列は就活サイトや対策本で、従来型の計数の一つとして紹介されます。公式ページの「与えられた条件をもとに、適切な解を導く問題」に当たる形です。規則の種類は多くないので、確かめる順番を決めておけば短時間で解けます。

## 何を測る問題か

数列で問われるのは計算の速さより、規則の候補を順に試して外れを捨てる力です。暗号や推論と同じく、「仮説を立てて、すべての項で確かめる」という考え方が土台になります。

## 問題の形

数が5〜7個並び、最後や途中が空欄になっています。選択肢から1つ選ぶ形が基本です。よく使われる規則は次のとおりです。

| 規則 | 例 | 見分け方 |
|---|---|---|
| 差が一定 | 3, 7, 11, 15 | 差がすべて同じ |
| 差が変化する | 1, 2, 4, 7, 11 | 差を並べると、さらに規則がある |
| 比が一定 | 3, 6, 12, 24 | 何倍かが同じ |
| 交互の操作 | 1, 3, 2, 6, 5 | 差や比が1つおきに同じ |
| 前の2項を使う | 1, 2, 3, 5, 8 | 前の2つを足すと次になる |
| 分数 | 1/3, 2/5, 3/7 | 分子と分母を別々に見る |

## 解き方の手順

1. **隣どうしの差を書く。** ほとんどの問題はここで規則が見えます。
2. **差が一定でなければ、差の差を書く。** 差が1, 3, 5, 7のように規則的に増えるなら、次の差も分かります。
3. **増え方が急なら比を見る。** 何倍かずつ増えていないか確かめます。
4. **差が＋と－で入れ替わるなら、1つおきに見る。** 奇数番目と偶数番目に分けたり、操作を交互に繰り返していないか確かめます。
5. **分数は分子と分母を別の列として見る。** それぞれが別の数列になっていることが多いです。
6. **見つけた規則を最初の項から当てはめ直す。** 途中の項だけに合う規則を選ばないためです。

## よくある落とし穴

- **差の差まで見ない。** 差が一定でないとすぐ諦めてしまうのが一番多い失敗です。
- **最後の差をそのまま繰り返す。** 差が増えていく数列で、最後の差を足しただけの数は、ほぼ必ず選択肢に入っています。
- **交互の操作の順番を間違える。** 次がどちらの操作の番かを、項の位置で確かめます。
- **分数を約分してしまう。** 8/12のように約分できる形でも、規則どおりなら約分しないまま選択肢に出ます。規則が作る形そのものを選んでください。

## 時間配分

数列は暗号や推論より短く済むことが多い問題です。手順1と2で規則が見えれば30秒、見えなくても1分半で手順6まで終えるのが目安です。それ以上かかるときは、いったん選択肢を見て、どれが規則に合いそうか逆から確かめる方法もあります。

## 練習問題

次の3問は、このガイドのために作ったオリジナル問題です。TG-WEBやヒューマネージの資料、ほかの対策サイトから取ったものではありません。（　）に入る数を選んでください。

**問1.** 2, 3, 5, 9, 17,（　）

ア. 25　イ. 31　ウ. 33　エ. 34　オ. 35

**問2.** 2, 6, 4, 12, 10, 30,（　）

ア. 26　イ. 28　ウ. 32　エ. 60　オ. 90

**問3.** 1/2, 2/3, 3/5, 5/8,（　）

ア. 6/11　イ. 7/12　ウ. 8/12　エ. 8/13　オ. 13/21

<details>
<summary>解答と解説（問1〜3）</summary>

**問1：ウ（33）。** 差は1, 2, 4, 8で、毎回2倍になっています。次の差は16なので、17＋16＝33です。*アではない理由：* 25は最後の差の8をもう一度足した数です。

**問2：イ（28）。** 「3倍する」「2を引く」を交互に繰り返しています。2×3＝6、6－2＝4、4×3＝12、12－2＝10、10×3＝30と進み、次は2を引く番なので30－2＝28です。*オではない理由：* 90はもう一度3倍した数で、操作の順番を取り違えています。

**問3：エ（8/13）。** 次の分子は前の分母、次の分母は前の分子と分母の和です。1/2→2/3→3/5→5/8と確かめられ、次は分子が8、分母が5＋8＝13です。分子だけを見ると1, 2, 3, 5、分母だけを見ると2, 3, 5, 8で、どちらも前の2つを足すと次になる数列になっています。*ウではない理由：* 分母を1つずつ増やすと考えた形で、5/8→8/12は規則に合いません。*オではない理由：* 1つ先の項です。

</details>

## 自己採点

| 問 | 1 | 2 | 3 |
|---|---|---|---|
| 正解 | ウ | イ | エ |

- **3問正解：** 数列は得点源にできます。1問1分以内を目標に、暗号や推論に時間を回してください。
- **2問正解：** 間違えた問題が表のどの規則だったかを確認し、その規則を手順の何番目で試すべきだったかを書き出してください。
- **1問以下：** 手順1〜6の順番を毎回そのまま守る練習から始めましょう。差を必ず書く習慣だけで、正答率はかなり上がります。
