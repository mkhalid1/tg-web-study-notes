# 従来型と新型の見分け方

TG-WEB対策で最初にやるべきことは、自分が受けるのが従来型か新型かの見当をつけることです。同じTG-WEBでも、従来型は「解き方を知らないと手が止まる」問題、新型は「知っていても速く処理しないと終わらない」問題で、練習の中身がまるで違います。

## まず押さえておくこと

- 「従来型」「新型」は就活サイトや対策本での呼び名です。ヒューマネージの公式ページでは、この呼び名は確認できません。
- 公式ページにあるのは、判断推理力検査 i9（30分、設問数が少なめ）と基礎能力検査 i9neo（15分、設問数が多め）という検査の説明です。このガイドでは、従来型をi9に、新型をi9neoに近いものとして扱っていますが、これは公式の対応表ではなくこのガイドの読み方です。
- どの検査を使うかは企業が選びます。同じ企業でも年度や職種で変わることがあります。

## 見分ける手がかり

### 1. 制限時間と問題数

受検画面や案内で制限時間や問題数が分かる場合は、それが一番の手がかりです。就活サイトでよく紹介される目安（非公式）と比べてみてください。

| 科目 | 従来型の目安 | 新型の目安 |
|---|---|---|
| 言語 | 12問・12分 | 34問・7分 |
| 計数 | 9問・18分 | 36問・8分 |

1問あたり1分以上あれば従来型、1問あたり十数秒しかなければ新型、と考えると分かりやすいです。この数字は[就活の教科書](https://reashu.com/tgweb-kigyo/)など就活サイトの情報で、ヒューマネージは公表していません。

### 2. 問題の見た目

| 見えるもの | 近いのは |
|---|---|
| 暗号、うそつき、順位、展開図、一筆書き | 従来型 |
| 長めの文章を読んで要旨を選ぶ、文の並べ替え | 従来型 |
| 同義語・対義語、言葉の意味 | 新型 |
| 表を読み取る、計算式の空欄を埋める | 新型 |

公式の説明でも、i9は「文章の並び替えや要旨の把握」「条件から解を導く問題」「空間把握」、i9neoは「意味の近い単語や対立する単語」「表の読み取りや計算の穴埋め」とされています。

### 3. 先輩の体験談や就活サイトの企業別情報

「〇〇社は従来型だった」という情報は役に立ちますが、公式な情報ではありません。年度が変われば検査も変わり得るので、参考程度にとどめてください。

## どちらか分からないときの準備

どちらか分からないまま受ける人も少なくありません。その場合は次の順で準備するのが効率的です。

1. **従来型の解き方を先に覚える。** 暗号・推論・展開図は、手順を知らないと1問に何分もかかります。逆に手順さえ覚えれば、点が一番伸びやすい部分です。
2. **新型は時間を計った計算と語彙の練習で補う。** 新型は1問ごとの難しさより処理の速さが問われます。新型の中身は[新型（計数・言語）の概要](sections/new-type.md)にまとめました。
3. **性格・適性検査があるかも確認する。** 能力検査と組み合わせて出ることがあります。[性格・適性検査](personality.md)を見てください。

## 受検方式も確認しておく

TG-WEBには、自宅で受けるWEB方式のほかに、テストセンター方式、マークシート方式、オンライン監視型のWEB会場方式、AIが受検中の様子を監視する「TG-WEB eye」があります（公式）。案内メールで方式を確認し、AI監視型なら静かな部屋とカメラの準備が必要です。詳しくは[受検当日のチェックリスト](test-day-checklist.md)を見てください。
