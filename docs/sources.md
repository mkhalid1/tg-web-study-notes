# 出典一覧

TG-WEBについての事実は、ヒューマネージの公式ページで確認できるものだけを使っています。就活サイトの情報を使った箇所は、本文中で「非公式」「就活サイトの目安」と明記しています。すべて2026年11月25日に確認しました。

## 公式：ヒューマネージ

- [ヒューマネージの適性検査 TG-WEB（トップ）](https://tg-web.humanage.co.jp/)：導入3,200社以上・年間60万人以上の利用、新卒採用向け・キャリア採用向け・従業員向けの3種類
- [ラインナップ](https://tg-web.humanage.co.jp/lineup/)：検査の一覧
- [知的能力検査 i9 / C3 / J3 / P3](https://tg-web.humanage.co.jp/lineup/i9.html)：i9、i9neo、i9e、C3、J3、P3の内容、検査時間、基準レベル、受検方式、IRTによる出題
- [B5](https://tg-web.humanage.co.jp/lineup/b5.html)、[A8（Another8）](https://tg-web.humanage.co.jp/lineup/a8.html)、[G9](https://tg-web.humanage.co.jp/lineup/g9.html)、[E9](https://tg-web.humanage.co.jp/lineup/e9.html)、[W8](https://tg-web.humanage.co.jp/lineup/w8.html)、[Q1](https://tg-web.humanage.co.jp/lineup/q1.html)、[U1](https://tg-web.humanage.co.jp/lineup/u1.html)、[P8](https://tg-web.humanage.co.jp/lineup/p8.html)：性格・適性の検査の内容と検査時間
- [活用シーン](https://tg-web.humanage.co.jp/service/)：分析レポート、本人向け・上司向けフィードバックシート
- [オンラインAI監視型WEBテスト TG-WEB eye](https://www.humanage.co.jp/service/assessment/tg-web/eye/index.html)：5つの受検方式、AI監視のしくみ、TG-WEBがシリーズの総称であること、組み合わせ例の所要時間

## 非公式：就活サイト

- [就活の教科書「TG-WEBを出題する企業一覧」](https://reashu.com/tgweb-kigyo/)：従来型・新型の問題数と時間の目安（言語12問12分、計数9問18分、英語10問15分、新型言語34問7分、新型計数36問8分）。ヒューマネージは公表していない数字です。

## 検索データ

- 「よくある質問」に載せた質問は、Googleの日本の検索結果（言語：日本語）で「TG-WEB」「TG-WEB 対策」に表示された「他の人はこちらも質問」と関連検索から選びました（DataForSEO、2026年11月25日取得）。

## このガイド自身の考え

次の内容は公式情報ではなく、このガイドの解釈や学習上のすすめです。

- 従来型をi9に、新型をi9neoに近いものとして扱うこと
- 各タイプの解き方の手順、落とし穴、時間配分のすすめ
- 練習で7〜8割の正答を目安にすること
- 練習問題21問（すべてオリジナル）とその解説

## 提携関係について

このガイドは独立した学習用の資料で、リンクしているPrepClubsの模擬テストもTG-WEBの公式教材ではありません。株式会社ヒューマネージや、TG-WEBを利用する企業とは関係がなく、推奨や後援も受けていません。TG-WEBおよび各検査の名称は、それぞれの権利者の商標です。
