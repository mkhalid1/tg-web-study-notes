# 性格・適性検査

TG-WEBでは、言語・計数（公式では数理）の能力検査に加えて、性格や行動の特徴を測る検査が組み合わされることがあります。能力検査と違って正解はありません。対策の目的は「よく見せること」ではなく、「自分の普段の姿を、ぶれずに答えられるようにすること」です。

## どんな検査があるか

ヒューマネージの公式ラインナップに載っている主な検査です。どれを使うかは企業が選びます。

| 検査 | 測るもの（公式の説明の要約） | 検査時間（公式） |
|---|---|---|
| B5（ベーシックパーソナリティ） | ビッグファイブ理論に基づく5つの性格特性（外向性・協調性・誠実性・開放性・情緒安定性）と、成果を阻害する要因（ディレールメント） | 15分 |
| A8（Another8、コンピテンシー） | 知識やスキルを成果につなげる行動を起こせるか。過去の行動事実を思い出しながら答える | 15分 |
| G9（コーピング） | ストレスの原因に対処・解決する力と、ストレスからの回復力 | 新卒採用版10分、キャリア版15分 |
| E9（エモーショナル・インテリジェンス） | 自尊・共感・ソーシャルスキルの3つの軸から見たEQ（感情知能） | 10分 |
| W8（チーム・コミュニケーション） | 自尊と他尊のバランスから見た、チームで成果を出す力 | 10分 |
| Q1（ジョブ・クラフティング） | 仕事に工夫を加え、自らエンゲージメントを高める力 | 10分 |
| U1（グローバルリーダーシップ） | グローバルな環境でも活躍できるか | 10分 |
| P8（ハピネス） | 仕事に喜びや幸せを感じられるか | 10分 |

公式ページによると、TG-WEBの結果は人事向けの分析レポートのほか、受検者本人に渡せるフィードバックシートや、配属先の上司向けのフィードバックシートとしても使われます。

## 公式の説明から分かること

- **B5は「極端さ」も見ている。** 公式ページは、B5が性格に加えて「極端に不安定な部分や大きく欠落している部分がないか」を確認すると説明しています。すべての質問に極端な答えを続けると、かえって目立つ可能性があります。
- **A8は過去の事実を聞いている。** 公式ページによると、A8は「自らの過去の行動事実を思い出しながら回答する手法」を採用しています。理想の自分ではなく、実際にやってきたことを思い出して答える検査です。
- **G9は我慢強さではなく対処の仕方を見ている。** 公式ページは、G9が「我慢したり逃避したりするのではなく、行動や考え方を変えることで、ストレスの原因を対処・解決する力」を測ると説明しています。
- **結果は面接にも使われる。** E9やW8、G9の公式ページは、分析レポートに面接での確認ポイントが載ると説明しています。検査で答えた内容について、面接で具体的に聞かれることがあると考えておきましょう。

## 答えるときの心がけ

1. **普段の自分で答える。** 「企業が好みそうな答え」を考えながら答えると、質問ごとに基準がぶれます。
2. **同じことを違う言い方で聞かれても、答えをそろえる。** 性格検査では一般に、似た内容の質問が言い回しを変えて出ることがあります。
3. **A8のような行動の質問では、具体的な場面を思い出す。** アルバイト、ゼミ、部活動などで実際にとった行動を思い浮かべてから答えると、迷いが減ります。
4. **エントリーシートや面接で話す自分と矛盾させない。** 検査の結果と面接での話が食い違うと、どちらの印象も弱くなります。
5. **時間をかけすぎない。** 1問ごとに考え込まず、最初に浮かんだ答えを基本にします。

## 準備しておくとよいこと

- 自分の強みと弱みを、具体的なエピソードつきで3つずつ書き出しておく。
- ストレスを感じた場面で、実際にどう対処したかを2〜3例思い出しておく。
- チームで動いたときに、自分がどんな役割をとることが多いかを整理しておく。

この準備は、性格検査のためだけでなく、面接の準備としてもそのまま役に立ちます。
