# 受検当日のチェックリスト

## 受検方式を確認する

TG-WEBには、公式に次の受検方式があります。どの方式かで準備が変わるので、案内メールで必ず確認してください。

| 方式 | 準備すること |
|---|---|
| WEB方式 | 自宅などのパソコンで受検。通信環境と静かな場所 |
| オンラインAI監視型WEB方式（TG-WEB eye） | 上に加えて、カメラが使えること。公式ページによると、AIが替え玉受検やカンニングを監視し、不審な行動は受検結果とともに企業へ報告される |
| テストセンター方式 | 指定の日時に会場へ行く。会場の案内に従う |
| オンライン監視型WEB会場方式 | 指定の日時にWebテストを受ける |
| マークシート方式 | 会場で紙の検査を受ける。筆記用具 |

## 前日まで

- [ ] 受検の締め切り日時と、受検方式を確認した
- [ ] ログインIDとパスワード、受検用URLを確認した
- [ ] 能力検査に加えて性格検査があるかを確認した
- [ ] ミスノートを見直した（新しい問題には手を出さない）
- [ ] 筆算用の紙とペンを用意した（使ってよいかは案内に従う）

## 1時間前

- [ ] パソコンを再起動し、不要なアプリやタブを閉じた
- [ ] 電源につないだ。通信が安定しているか確かめた
- [ ] AI監視型の場合、カメラが映るか、周りに人や物がないかを確認した
- [ ] スマートフォンの通知を切った

## 受検が始まったら

- [ ] 最初の説明画面で、制限時間と問題数、前の問題に戻れるかを確認した
- [ ] 制限時間と問題数から、従来型か新型かの見当をつけた（[見分け方](how-to-tell-types.md)）
- [ ] 1問あたりの目安時間を決めた（[時間配分](timing.md)）

## 受検中

- 暗号：例をすべて確かめてから選ぶ
- 推論：条件を記号で書き出してから考える
- 数列：差を書く、差の差を書く
- 展開図：一直線に3つ並んだ両端が向かい合う
- 言語：本文に根拠がある選択肢だけを選ぶ
- 1分考えて方針が立たない問題は、選択肢を絞って決めて次へ

## 終わった後

- 覚えている問題のタイプと、迷った理由をミスノートに書く。次の選考でまたTG-WEBが出たときに役立ちます。
- 性格検査で答えた内容を、面接の前に思い出しておく。

## 最後の練習

受検前にもう一度だけ時間を計って解いておきたいときは、従来型と同じ形式の[PrepClubsの無料TG-WEB形式模擬テスト](https://prepclubs.com/ja/tg-web-taisaku?utm_source=github&utm_medium=referral&utm_campaign=study-notes&utm_content=tg-web)（21問・30分）が使えます。

出典：[オンラインAI監視型WEBテスト TG-WEB eye（公式）](https://www.humanage.co.jp/service/assessment/tg-web/eye/index.html)（2026年11月25日確認）
