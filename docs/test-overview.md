# TG-WEBとはどんな検査か

TG-WEBは、株式会社ヒューマネージが提供する適性検査シリーズの総称です。就活生の間では「SPIや玉手箱と違って、見たことのない問題が出るWebテスト」として知られています。なお、公式ページでは「言語・数理」、就活サイトでは「言語・計数」と呼ぶことが多く、このガイドの「計数」は公式の「数理」と同じものを指します。このページでは、ヒューマネージの公式ページで確認できる事実と、就活サイトで一般に言われていることを分けて整理します。

## 基本情報

| 項目 | 内容 | 出どころ |
|---|---|---|
| 提供元 | 株式会社ヒューマネージ | 公式 |
| 導入実績 | 導入3,200社以上、年間60万人以上が利用 | 公式トップページ |
| 対象別の検査 | 新卒採用向け、キャリア採用向け、従業員向けの3種類 | 公式トップページ |
| 受検方式 | マークシート、WEB、テストセンター、オンライン監視型WEB会場、オンラインAI監視型WEB（TG-WEB eye） | 公式 TG-WEB eye ページ |
| 能力検査の例 | 判断推理力検査 i9（30分）、基礎能力検査 i9neo（15分）、英語能力検査 i9e（15分）ほか | 公式ラインナップ |
| 性格・適性の検査 | B5、A8（Another8）、G9、E9、W8、Q1、U1、P8 など | 公式ラインナップ |
| 合格ライン | 公表されていない。企業ごとに判断する | 公式に記載なし |
| 「従来型」「新型」 | 就活サイトでの呼び名。公式ページでは確認できない | 就活サイト |

## 能力検査のラインナップ

ヒューマネージは、言語・数理の能力を測る検査を「知的能力検査」としてまとめています。公式ページの説明は次のとおりです。

| 検査 | 時間 | 公式ページでの説明（要約） |
|---|---|---|
| 判断推理力検査 i9 | 30分 | 言語：文章の並び替えや要旨の把握。数理：与えられた条件から適切な解を導く問題、空間把握を必要とする問題。i9neoより時間が長く設問数が少ない |
| 基礎能力検査 i9neo | 15分 | 言語：意味の近い単語・対立する単語、言葉の意味。数理：表の読み取り、計算の穴埋め。i9より時間が短く設問数が多い |
| 英語能力検査 i9e | 15分 | TOEICのReadingパートと同じ形式。空欄補充と文書の読解。TOEIC換算得点も算出 |
| 考察力検査 C3 | 30分（60分版もある） | 言語考察力・数理考察力。マークシート方式 |
| 事務処理能力検査 J3 | 30分 | 計算処理・言語理解・論理基礎。マークシート方式 |
| 一般常識検査 P3 | 50分 | 国語・英語・数学・時事。マークシート方式 |

i9とi9neoはどちらも基準レベルが「4年制大学卒業レベル」で、IRT（項目反応理論）に基づいてランダムに出題されると公式に書かれています。i9はテストセンター、AI監視型WEB、WEB、マークシートの4方式、i9neoはAI監視型WEBとWEBの2方式に対応しています。

## 「従来型」と「新型」について

就活サイトでは、TG-WEBの能力検査を「従来型（旧型）」と「新型」に分けて説明するのが一般的です。従来型は問題数が少なく一問ごとに考えさせる難問型、新型は易しめの問題を短時間で大量に解くスピード型、という説明です。

ヒューマネージの公式ページでは、この「従来型」「新型」という言葉は確認できませんでした。ただし、i9（時間が長く設問数が少ない、並び替え・要旨把握・条件推理・空間把握）とi9neo（時間が短く設問数が多い、同義語・対義語・表の読み取り・計算の穴埋め）の公式説明は、就活サイトの従来型・新型の説明とよく重なります。このガイドでは「従来型はi9に近く、新型はi9neoに近い」と読んでいますが、これはヒューマネージの公式見解ではなく、このガイドの解釈です。詳しくは[従来型と新型の見分け方](how-to-tell-types.md)を見てください。

就活サイトでよく紹介される問題数と時間の目安（非公式）は次のとおりです。公式には公表されていない数字なので、あくまで参考にしてください。

| 科目 | 従来型 | 新型 |
|---|---|---|
| 言語 | 12問で12分 | 34問で7分 |
| 計数 | 9問で18分 | 36問で8分 |
| 英語 | 10問で15分 | 記載なし |

出典：[就活の教科書「TG-WEBを出題する企業一覧」](https://reashu.com/tgweb-kigyo/)（就活サイト、2026年11月25日確認）。従来型の言語と計数を足すと30分、新型を足すと15分で、公式のi9（30分）とi9neo（15分）の検査時間と一致します。ただし、科目ごとの内訳や問題数そのものは公式には公表されていません。

## 従来型で出る問題のタイプ

公式ページが挙げているのは「並び替え」「要旨の把握」「条件から解を導く問題」「空間把握」までです。就活サイトや対策本では、これをさらに細かく次のように呼ぶのが一般的で、このガイドもその分け方に合わせています。

| 科目 | 問題のタイプ | このガイドのページ |
|---|---|---|
| 計数 | 暗号 | [暗号](sections/code-puzzles.md) |
| 計数 | 推論（順位・うそつき・配置） | [推論](sections/logic-puzzles.md) |
| 計数 | 数列 | [数列](sections/number-series.md) |
| 計数 | 展開図・図形 | [展開図・図形](sections/figures.md) |
| 言語 | 長文読解・空欄補充・並べ替え | [言語](sections/verbal.md) |

## 性格・適性の検査

能力検査とは別に、性格や行動特性を測る検査が組み合わされることがあります。ビッグファイブ理論に基づくB5、過去の行動事実から答えるA8（Another8）、ストレス対処力を測るG9などです。正解のある検査ではないので、対策の考え方は能力検査とまったく違います。[性格・適性検査](personality.md)にまとめました。

## 時間を計って試す

従来型の問題は、形式を知っているかどうかで解ける速さが大きく変わります。まず[5分診断](diagnostic.md)で苦手を見つけ、本番に近い感覚を確かめたいときは、従来型と同じ形式の[PrepClubsの無料TG-WEB形式模擬テスト](https://prepclubs.com/ja/tg-web-taisaku?utm_source=github&utm_medium=referral&utm_campaign=7n35ny&utm_content=tg-web)（21問・30分）を使ってみてください。
