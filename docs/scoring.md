# 結果と評価のしくみ

先に結論です。TG-WEBの合格ラインは公表されていません。何点で通過かは企業が判断します。受検者に点数が伝えられるかどうかも、公式ページには書かれていません。このページでは、公式に分かっていることと、分かっていないことを分けて説明します。

## 公式に分かっていること

- **問題はIRT（項目反応理論）に基づいてランダムに出題される。** 判断推理力検査 i9と基礎能力検査 i9neoについて、公式ページにこう書かれています。受検者ごとに出る問題が違うということです。
- **基準レベルは4年制大学卒業レベル。** i9、i9neo、i9e、C3の公式説明にあります。
- **結果は企業向けの分析レポートになる。** 公式ページによると、分析レポートは全体平均と比べた項目別の結果や、カテゴリー・タイプが表示されます。
- **本人向け・上司向けのフィードバックシートもある。** 受検者本人に返せるシートと、配属先の上司向けのシートが用意されています。使うかどうかは企業の判断です。
- **i9eはTOEIC換算得点も出す。** 英語能力検査 i9eの公式説明にあります。

## IRTとはどういうことか

IRTは、問題ごとの難しさや性質をあらかじめ数値で把握しておき、どの問題に正解したかから能力を推定する考え方です。一般的な説明として、次の2つを押さえておけば十分です。

1. **人によって出る問題が違っても、同じ物差しで比べられる。** だから「友人と同じ問題が出る」とは限りません。
2. **正解した数だけでなく、どの問題に正解したかが効く。** ただし、TG-WEBで具体的にどう計算しているかは公表されていません。

ここに書いたのはIRTという方法の一般的な性質です。

## 公式には分かっていないこと

| よくある疑問 | 公式の情報 |
|---|---|
| 何割取れば合格か | 公表されていない |
| 誤答で減点されるか | 公表されていない |
| 点数が受検者本人に知らされるか | 公式ページに記載なし。本人向けフィードバックシートを使うかどうかは企業しだい |
| 結果を別の企業で使い回せるか | 公表されていない。企業の案内に従う |

就活サイトでは「何割取れば通過」といった数字が紹介されることがありますが、ヒューマネージは合格ラインを公表していません。基準は企業や職種ごとに違うと考えてください。

## このガイドからの目安

公式な基準ではありませんが、練習の目標としては次のように考えると準備しやすいです。

- **時間内に全問に答える。** 減点の有無が公表されていない以上、空欄で終わるより、最後まで答えたほうが損をしにくいと考えられます。
- **各タイプの手順を見ないで使える状態にする。** 従来型は、手順を思い出す時間がそのまま失点になります。
- **練習では7〜8割の正答を目安にする。** 本番の緊張や見慣れない問題に備えた余裕です。これはこのガイドの練習上の目安で、公式な合格ラインではありません。
