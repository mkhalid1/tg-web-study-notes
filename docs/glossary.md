# 用語集

このガイドに出てくる言葉を、五十音順ではなくテーマごとにまとめました。「公式」とあるものはヒューマネージの公式ページで使われている言葉、「就活サイト」とあるものは就活サイトや対策本で使われる呼び名です。

## 検査と方式

| 用語 | 意味 |
|---|---|
| TG-WEB | ヒューマネージが提供する適性検査シリーズの総称（公式） |
| ヒューマネージ | TG-WEBを提供する会社。採用管理システム i-web も提供している |
| i9（判断推理力検査） | 言語・数理の論理的思考力を30分で測る検査。並び替え、要旨把握、条件推理、空間把握（公式） |
| i9neo（基礎能力検査） | 言語・数理の基礎能力を15分で測る検査。同義語・対義語、表の読み取り、計算の穴埋め（公式） |
| i9e（英語能力検査） | 英語力を15分で測る検査。TOEICのReadingパートと同じ形式（公式） |
| C3、J3、P3 | 考察力検査、事務処理能力検査、一般常識検査。いずれもマークシート方式（公式） |
| 従来型（旧型） | 問題数が少なく難しめの能力検査を指す呼び名（就活サイト）。このガイドではi9に近いものとして扱う |
| 新型 | 問題数が多くスピード重視の能力検査を指す呼び名（就活サイト）。このガイドではi9neoに近いものとして扱う |
| TG-WEB eye | AIが受検中の様子を監視する、オンラインAI監視型WEBテスト（公式） |
| テストセンター方式 | 指定の会場で受ける方式（公式） |
| 基準レベル | 検査が想定する学歴レベル。i9などは4年制大学卒業レベル（公式） |
| IRT（項目反応理論） | 問題ごとの難しさなどを数値で把握し、どの問題に正解したかから能力を推定する考え方。i9とi9neoはこれに基づきランダムに出題される（公式） |

## 能力検査の問題タイプ

| 用語 | 意味 |
|---|---|
| 計数 | 数の問題を指す就活サイトでの呼び名。公式ページの「数理」と同じ（就活サイト） |
| 暗号 | 言葉が規則にしたがって記号や数字に置き換えられ、その規則を見抜く問題（就活サイト） |
| 推論 | 条件や発言から、順位・配置・うそつきなどを確定させる問題（就活サイト） |
| 数列 | 並んだ数の規則を見つけ、空欄の数を答える問題（就活サイト） |
| 展開図 | 立方体などを切り開いた図。組み立てたときの面の位置を問う（就活サイト） |
| 一筆書き | 同じ線を2度通らずに図形を描くこと。奇数本の線が集まる点が0個か2個ならできる |
| 長文読解 | 文章を読み、内容と合うものや筆者の主張を選ぶ問題（就活サイト） |
| 空欄補充 | 文章中の空欄に合う語句を選ぶ問題（就活サイト） |
| 並べ替え | ばらばらの文を意味が通る順に並べる問題（公式の説明では「文章の並び替え」） |

## 性格・適性検査

| 用語 | 意味 |
|---|---|
| ビッグファイブ | 外向性・協調性・誠実性・開放性・情緒安定性の5つで性格をとらえる理論。B5の土台（公式） |
| ディレールメント | 成果を阻害する要因、問題行動のリスク。B5で測る（公式） |
| コンピテンシー | 知識やスキルを成果につなげる行動を起こす力。A8（Another8）で測る（公式） |
| コーピング | ストレスの原因に対処・解決する力。G9で測る（公式） |
| ジョブ・クラフティング | 仕事に工夫を加える力。Q1で測る（公式） |
| 自尊・他尊 | 自分の価値を認めようとする傾向と、他者を理解し援助しようとする傾向。W8で使われる考え方（公式） |
