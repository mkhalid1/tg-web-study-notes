# 時間配分

TG-WEBの従来型で点を落とす一番の原因は、難しい1問に時間を使いすぎて、解けるはずの問題に手が回らなくなることです。ここでは、公式に分かっている検査時間と、就活サイトの目安をもとにしたペース配分を整理します。

## 公式に分かっている検査時間

| 検査 | 検査時間 |
|---|---|
| 判断推理力検査 i9（言語・数理） | 30分 |
| 基礎能力検査 i9neo（言語・数理） | 15分 |
| 英語能力検査 i9e | 15分 |
| B5、A8 | 各15分 |
| G9 | 新卒採用版10分、キャリア版15分 |
| E9、W8、Q1、U1、P8 | 各10分 |

公式のTG-WEB eyeのページには、B5、G9、知的能力（言語・数理）を組み合わせた例で「所要時間：最大55分」とあります。実際に何を組み合わせるかは企業が決めます。

## 就活サイトの目安（非公式）

| 科目 | 問題数と時間 | 1問あたり |
|---|---|---|
| 従来型 言語 | 12問・12分 | 約1分 |
| 従来型 計数 | 9問・18分 | 約2分 |
| 従来型 英語 | 10問・15分 | 約1分30秒 |
| 新型 言語 | 34問・7分 | 約12秒 |
| 新型 計数 | 36問・8分 | 約13秒 |

出典は[就活の教科書](https://reashu.com/tgweb-kigyo/)などの就活サイトで、ヒューマネージの公表ではありません。

## 従来型 計数のペース配分

18分で9問なら、1問2分です。ただし、問題ごとにかかる時間は大きく違います。

1. **最初の説明画面で、前の問題に戻れるかを確認する。** 戻れない形式なら、飛ばして後で解くという作戦は使えません。
2. **数列は1分以内に終える。** ここで浮いた時間を暗号や推論に回します。
3. **暗号・推論は1分考えて方針が立たなければ切り替える。** 前の問題に戻れる形式なら、いったん飛ばして後で戻ります。戻れない形式なら、選択肢を2つに絞って決め、次へ進みます。
4. **展開図は手順どおりに。** 頭の中で組み立てようとせず、一直線に3つ並べるルールを使います。

## 従来型 言語のペース配分

12分で12問なら、1問1分です。

- **長文読解：** 本文に1分半、設問1つに30〜40秒。
- **空欄補充：** 前後の関係を決めるのに30秒。
- **並べ替え：** 先頭になれない文を消すのに20秒、残りで40秒。

## 時間が足りないときの決め方

- **迷ったら選択肢を2つに絞って選ぶ。** 空欄で終えるより、絞ってから選ぶほうが正解する確率は上がります。
- **見直しは最後に時間が残ったときだけ。** 従来型は、1問の見直しより次の1問を解くほうが点につながりやすいです。
- **焦ったら、手順の最初に戻る。** 推論なら条件を書き出す、暗号なら文字数を比べる、のように最初の一歩に戻ると立て直せます。

## 時間を計って練習する

ペース配分は、頭で分かっていても本番では崩れます。従来型と同じ形式の[PrepClubsの無料TG-WEB形式模擬テスト](https://prepclubs.com/ja/tg-web-taisaku?utm_source=github&utm_medium=referral&utm_campaign=study-notes&utm_content=tg-web)（21問・30分）で、実際に時計を見ながら解いてみてください。
